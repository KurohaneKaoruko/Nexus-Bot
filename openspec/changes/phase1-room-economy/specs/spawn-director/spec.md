# Spec Delta

## Purpose

以能力缺口驱动 Creep 生产：聚合无法分配的任务生成生产请求，用模板生成合法身体，排程并按替补窗口保持劳动力连续，死亡后完整回收。

## ADDED Requirements

### Requirement: 缺口聚合生产
系统必须把当前无法分配的任务按所需能力聚合为生产请求（用途、预算、优先级、目标房间），同一缺口在请求存续期内去重；有闲置 Spawn 时按优先级消费队列。

#### Scenario: 未分配任务产生请求
- **WHEN** 存在因缺劳动力而无法分配的采集任务
- **THEN** 产生对应用途的生产请求，且同缺口不重复排队

#### Scenario: 请求随缺口消失
- **WHEN** 该缺口对应的任务已被分配且不再缺劳动力
- **THEN** 未开始生产的对应请求被撤销

### Requirement: 模板化身体生成
身体必须由验证过的模板按能源预算扩展或缩减生成，且不超过身体部件与房间能量的合法上限；预算低于模板最低可行成本时不生产该单位。

#### Scenario: 预算充足按模板扩展
- **WHEN** 房间可用能量高于模板基础成本
- **THEN** 按模板比例扩展身体部件，总成本不超过预算

#### Scenario: 预算不足拒绝或降级
- **WHEN** 可用能量低于模板最低可行成本
- **THEN** 不提交该生产请求（或按规则降级为更小模板），Spawn 不被无效请求占用

### Requirement: 生产排程与能源等待
生产必须尊重 Spawn 状态：正在生产时把完成时间纳入排程；队列按优先级稳定排序；Spawn 能量不足时等待积累，不得重复提交同一请求或生产中断。

#### Scenario: 高优先级先生产
- **WHEN** 队列中存在多个请求且 Spawn 空闲
- **THEN** 优先级最高（同级先到先得）的请求先进入生产

#### Scenario: 能量不足不空转
- **WHEN** 队首请求成本超过 Spawn 及其供能结构的当前能量
- **THEN** Spawn 等待能量积累，该请求保持队首，闲置时间计入指标

### Requirement: 替补窗口
对 TTL 临近耗尽的关键劳动力，必须提前创建替补请求：提前量为生产时间加路程时间加安全余量；关键岗位允许短暂新旧重叠，廉价岗位不得长期重叠。

#### Scenario: 临期单位提前替补
- **WHEN** 某在岗单位的剩余寿命低于其替补提前量
- **THEN** 产生同用途的替补生产请求

#### Scenario: 死亡即回收
- **WHEN** 持有任务的 Creep 死亡
- **THEN** 其单位记录被终结、任务租约释放回池、替补需求立即生效

### Requirement: 生产命名可溯源
每个新 Creep 必须由唯一生成器命名（`代号-十六进制` 形式，代号来自角色代号表），并与生产请求的用途/任务关联，便于从名称追溯其职责与批次。

#### Scenario: 同批名称唯一可溯源
- **WHEN** 同一用途连续生产多个单位
- **THEN** 名称全部唯一，且可从名称识别角色代号
