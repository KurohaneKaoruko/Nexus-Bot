# Spec Delta

## Purpose

维修目标：受损建筑按威胁区域、战略价值与损坏程度排序生成维修任务，攻击期优先抢修关键防线，平时按维护线分级修缮，墙体/城门不无条件修到极限。

## ADDED Requirements

### Requirement: 受损结构产生维修任务

受损（耐久低于上限）的己方建筑必须产生维修任务，排序综合考虑战略价值（Spawn/塔/存储高于装饰性建筑）、损坏程度与是否处于威胁区域；任务生成幂等，同结构不重复。

#### Scenario: 关键受损结构优先

- **WHEN** 塔与道路同时受损
- **THEN** 塔的维修任务排序高于道路

#### Scenario: 同结构任务不重复

- **WHEN** 同一受损结构连续多 Tick 被规划
- **THEN** 仅存在一个维修任务（dedupe 键幂等）

### Requirement: 维修强度分级

维修目标线必须分级：威胁活跃期受损防线优先抢修，和平期按维护线修缮，墙体/城门默认修至配置的维护线即止，不无条件修到最大耐久。

#### Scenario: 和平期墙修到维护线即止

- **WHEN** 和平期墙体耐久低于维护线
- **THEN** 产生修缮任务并在达到维护线后完成，不继续修满

#### Scenario: 攻击期优先抢修防线

- **WHEN** 威胁活跃且防线（墙体/城门）正在受损
- **THEN** 抢修任务优先级提升，高于常规经济建造

### Requirement: 维修任务生命周期

维修任务在结构修复至目标线时完成、结构消失时终结并释放租约；被更高优先级任务抢占的单位释放后任务可被重新分配。

#### Scenario: 修复到位即完成

- **WHEN** 结构耐久恢复到任务目标线
- **THEN** 维修任务完成，执行单位回归可分配池

#### Scenario: 结构消失任务终结

- **WHEN** 维修目标结构被摧毁或不存在
- **THEN** 任务终结并释放租约，不占用执行单位
