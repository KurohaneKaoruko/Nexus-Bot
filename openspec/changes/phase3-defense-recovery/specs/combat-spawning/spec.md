# Spec Delta

## Purpose

战斗单位生产：defender 身体模板按能源预算伸缩生产，编制目标由威胁缺口驱动（和平期为零，不养常备军），生产能源经共享账本预留不重复花销。

## ADDED Requirements

### Requirement: 战斗角色身体模板

战斗角色必须定义可行走的身体段模板，按可用能源预算在最少/最多段数间伸缩；预算低于最少段成本时不生产，不得产出不可移动的身体。

#### Scenario: 预算不足不生产

- **WHEN** 可用能源低于角色最少段成本
- **THEN** 不提交该角色的生产请求

#### Scenario: 身体可行走

- **WHEN** 按预算生成战斗角色身体
- **THEN** 每段含移动部件，身体总段数受上限约束

### Requirement: 编制随威胁缺口驱动

Defender 编制目标必须由威胁等级与防御任务缺口推导：和平期目标为零，威胁出现按威胁分级提升目标并立即排产；威胁回落后编制目标回落，存续单位自然消亡不强制回收。

#### Scenario: 威胁出现排产

- **WHEN** 房间出现需要单位防御的威胁且 defender 在编加在途不足
- **THEN** SpawnDirector 按缺口与替补窗口提交 defender 生产请求

#### Scenario: 和平期不养常备军

- **WHEN** 无任何有效威胁
- **THEN** defender 编制目标为零，不为防御保留常驻单位

### Requirement: 生产能源经账本预留

战斗单位生产的能源承诺必须经共享资源账本预留：预留成功才排产，可用量随之扣减；预留过期或生产取消时释放，不与其他系统重复花同一笔能源。

#### Scenario: 预留后排产

- **WHEN** defender 生产请求进入排程
- **THEN** 对应能源已在账本预留，房间可用能源下降同一数额

#### Scenario: 取消时释放预留

- **WHEN** 生产请求被取消或预留过期
- **THEN** 账本释放该承诺，可用能源回升，无残留记账
