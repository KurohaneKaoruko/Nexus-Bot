# Spec Delta

## Purpose

防御应急响应：emergency 阶段按房间产出 defend/retreat 任务，非战斗单位受威胁时撤退停工，Safe Mode 按多条件政策启用，威胁驱动 war 姿态转移，攻击结束后经济自动恢复。

## ADDED Requirements

### Requirement: 应急阶段按房间规划

防御规划必须在 emergency 阶段（感知后、战略前）按房间执行：读快照与威胁摘要，幂等产出/终结防御任务（dedupe 键去重），受最高预算带保护，预算再紧张也不跳过威胁响应。

#### Scenario: 敌人出现即产出防御任务

- **WHEN** 房间出现有效威胁
- **THEN** 当 Tick 产出对应 defend 任务且幂等（重复规划不产生重复任务）

#### Scenario: 敌人消失任务终结

- **WHEN** 威胁源被清除或离开且威胁分回落
- **THEN** 对应 defend 任务被终结，不留孤儿任务占住租约

### Requirement: 非战斗单位撤退停工

威胁活跃期间，受威胁房间内的非战斗单位必须撤退到安全锚点（Spawn/核心区）或停止外出作业，不得持续采集直到死亡；撤退中的单位保持任务租约可恢复。

#### Scenario: 矿工受威胁撤离

- **WHEN** 敌人逼近矿工或采集点进入威胁范围
- **THEN** 非战斗单位向安全锚点撤退，不再原地采集

#### Scenario: 威胁解除恢复作业

- **WHEN** 威胁衰减至无害水平
- **THEN** 撤退结束，单位回到原经济任务继续产出，无需人工干预

### Requirement: 不长期困于防御

防御状态必须随威胁衰减自动解除：撤退任务在威胁消失后终结、防御编制回落，不得把所有单位长期困在防御状态。

#### Scenario: 战后无残留防御任务

- **WHEN** 威胁窗口结束后经过恢复窗口
- **THEN** defend/retreat 任务全部终结，经济任务族恢复正常排产

### Requirement: Safe Mode 多条件政策

Safe Mode 的触发必须满足多条件组合（关键结构濒毁 + 常规防御手段不足 + 可用次数/冷却允许），任何单一「敌人数量阈值」条件不得作为唯一依据；不可用时不得重复尝试。

#### Scenario: 关键结构濒毁触发

- **WHEN** Spawn/Controller 濒临被摧毁、塔火力不足以阻止且 Safe Mode 可用
- **THEN** 激活 Safe Mode 并记录原因

#### Scenario: 条件不满足不触发

- **WHEN** 仅出现少量可被塔处理的敌人，或 Safe Mode 处于冷却/耗尽
- **THEN** 不激活 Safe Mode，也不每 Tick 重复尝试

### Requirement: 威胁驱动姿态转移

战略姿态机必须以威胁分为输入：敌方出现置紧急重估标志，威胁分超阈值且过驻留迟滞进入 war 姿态（政策含更低风险容忍），威胁衰减后回到常规姿态；war 期间经济降级规则生效。

#### Scenario: 威胁超阈值进入 war

- **WHEN** 房间威胁分持续超过 war 阈值且满足驻留迟滞
- **THEN** 姿态转移为 war，政策与原因摘要更新

#### Scenario: 敌方出现即触发重估

- **WHEN** 可见房间新出现有效威胁
- **THEN** 紧急重估标志置位，战略重估不必等周期到期

#### Scenario: 威胁衰减退出 war

- **WHEN** war 期间威胁分回落并保持至退出阈值以下
- **THEN** 姿态离开 war 回到常规发展姿态，压制解除

### Requirement: 战斗单位行为经统一仲裁

Defender 单位按 defend 任务产出攻击/远程/治疗行动提案，经统一行动仲裁层提交；目标消失、租约丢失或任务终结时当 Tick 停止产出战斗意图。

#### Scenario: Defender 接战

- **WHEN** Defender 持有 defend 任务且目标在射程内
- **THEN** 其攻击/治疗意图经行动仲裁层提交并执行

#### Scenario: 目标消失停止战斗意图

- **WHEN** defend 任务的目标已不存在或任务已终结
- **THEN** 该单位不再产出对旧目标的战斗提案，任务按生命周期回收
