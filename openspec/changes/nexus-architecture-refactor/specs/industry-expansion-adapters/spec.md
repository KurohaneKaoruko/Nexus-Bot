# Spec Delta

## Purpose

产业/扩张/跨服收编：产业（市场、终端、实验室、工厂、核）逐子系统 Adapter 化经命令边界执行；扩张与跨服的意图（占领、预订、跨服调度）纳入命令边界；外矿链路的静默死锁（坐标口径、scout 饥饿）修复。

## ADDED Requirements

### Requirement: 产业动作经边界
产业的自主决策（自动交易、终端发送、核同步等）MUST 以命令提交命令边界执行并留结果记录；玩家控制台主动操作属人操豁免层，MUST 登记在守护清单。

#### Scenario: 自主交易不直连
- **WHEN** 自动市场模块决定成交
- **THEN** 交易命令经边界执行，失败有分类结果

#### Scenario: 终端发送留痕
- **WHEN** 产业模块决定跨房调拨资源
- **THEN** 终端发送以命令提交，结果与原因可查询

### Requirement: 扩张意图可计算
扩张候选 MUST 使用真实世界坐标换算（含 E/W 半球镜像），不得硬编码单半球邻房；扩张门槛（GCL 等）判定的结果 MUST 可观测——被否决时 MUST 有明确原因输出，不静默短路。

#### Scenario: 半球镜像正确
- **WHEN** 基房位于 W 半球且扩张姿态激活
- **THEN** 候选邻房为真实世界坐标邻房（含 W/E 两侧），扩张意图可产生

#### Scenario: 门槛否决不静默
- **WHEN** GCL 不足以扩张
- **THEN** 输出明确的 GCL 不足原因，而非无输出静默短路

### Requirement: 外矿链路不静默死锁
外矿链路（侦察、预订、远程采集、接力搬运）各环节 MUST 有进度可观测性：任一环节超过配置时限未推进时 MUST 产生告警；scout 编制 MUST 在外矿目标存在时参与孵化优先级竞争，不得被无限饥饿。

#### Scenario: scout 不被无限饥饿
- **WHEN** 外矿目标存在且 scout 缺编
- **THEN** scout 需求参与孵化仲裁并在时限内获得排期，超时告警

#### Scenario: 链路断点可定位
- **WHEN** 外矿收入为零持续超阈值
- **THEN** 告警能指出断点环节（侦察/预订/采集/搬运）

### Requirement: 跨服调度受管
跨服调度的决策（何时、送谁、带什么）MUST 产出可审计意图；跨服相关的 Memory 写入 MUST 受 schema 版本管理与容量约束。

#### Scenario: 跨服意图可审计
- **WHEN** 跨服模块做出调度决策
- **THEN** 意图记录可查询（来源、目标、理由），无静默丢弃
