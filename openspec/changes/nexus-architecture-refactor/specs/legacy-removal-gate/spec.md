# Spec Delta

## Purpose

旧实现删除门禁：legacy 代码只能在"Nexus 等价实现存在 + 生产验证 + 模拟验证 + CPU 验证"四条件齐备后删除；删除是收缩豁免清单、缩小系统表面积的过程，必须可回退、可审计。

## ADDED Requirements

### Requirement: 四条件删除门禁
删除任何 legacy 实现前 MUST 同时满足：（1）Nexus 等价实现已存在并接管该职责；（2）实服生产验证通过（对应行为在生产环境正常）；（3）sim 场景验证通过（对应场景门绿）；（4）CPU 验证通过（接管后 CPU 不劣化）。任一不满足 MUST 保留 legacy 路径。

#### Scenario: 条件不齐不删
- **WHEN** Nexus 等价已存在但生产验证未做
- **THEN** legacy 路径保留，删除被门禁拒绝

#### Scenario: 四条件齐备可删
- **WHEN** 四条件全部有通过记录
- **THEN** 对应 legacy 代码可删除，守护清单同步收缩

### Requirement: 删除可回退可审计
每次删除 MUST 关联验证记录（何种验证、何时、何证据）；删除 MUST 按最小可回退单元进行（一次一个职责域），不得跨域批量删除。

#### Scenario: 删除有关联证据
- **WHEN** 审计某次 legacy 删除
- **THEN** 可追溯其四条件验证记录

#### Scenario: 最小单元删除
- **WHEN** 一次删除操作涉及多个独立职责域
- **THEN** 被拒绝并要求按域拆分

### Requirement: 豁免清单单调收缩
架构守护的直连调用豁免清单 MUST 单调只减不增；legacy 删除进度以清单收敛度为度量；清单 MUST NOT 在删除后重新引入已移除条目（除非显式回退决策）。

#### Scenario: 清单不回涨
- **WHEN** 某版本删除了 N 个豁免条目
- **THEN** 后续版本的清单条目数不高于删除后水平，除非有显式回退记录

#### Scenario: 进度可度量
- **WHEN** 评估重构进度
- **THEN** 可获得豁免清单按域的收敛百分比
