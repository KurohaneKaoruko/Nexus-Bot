# Spec Delta

## Purpose

全局唯一突变边界：除感知、Memory 迁移与纯计算外，一切改变游戏状态的原生调用 MUST 经统一命令管线提交执行；命令管线负责校验、所有权检查、冲突消解、执行与结果分类；legacy 与外部模块经 Adapter 收编进边界。

## ADDED Requirements

### Requirement: 突变单点执行
任何模块 MUST NOT 在提交阶段之外直接调用改变游戏状态的原生 API（Creep/Room/Structure/Spawn/Market/Terminal 的动作类调用）。原生调用只允许出现在统一提交路径及其明确登记的 Adapter 执行层。

#### Scenario: 提交外无原生调用
- **WHEN** 审查一个 Tick 的执行过程
- **THEN** 全部原生行动调用都发生在提交阶段或登记的 Adapter 执行层，策略/协调/任务/感知阶段零调用

#### Scenario: 可观测层不突变
- **WHEN** 可视化或遥测模块发现异常孵化单
- **THEN** 它只产生告警，不调用孵化取消等突变 API

### Requirement: 全管线覆盖
命令边界 MUST 覆盖以下管线：Creep 工作类意图、移动、孵化、建造（工地创建/移除/拆除）、结构动作（塔/启用安全模式）、市场交易、终端发送、占领/预订控制器、PowerCreep 能力。新增结构动作类型时 MUST 登记到边界而非直连调用。

#### Scenario: 孵化经边界
- **WHEN** 任何模块请求生产一个单位
- **THEN** 该请求作为孵化命令进入统一管线，由孵化执行器统一调用原生孵化 API

#### Scenario: 建造经边界
- **WHEN** 规划器决定放置或移除一个工地
- **THEN** 通过建造命令提交执行，规划器自身不直接调用工地创建/移除 API

#### Scenario: 市场与终端经边界
- **WHEN** 产业模块决定市场交易或资源发送
- **THEN** 交易与发送以命令形式提交执行并留有结果记录

### Requirement: 命令管线处理次序
命令 MUST 依次经过登记 → 校验 → 所有权检查 → 冲突消解 → 执行 → 结果分类；校验失败、非 owner、同管线冲突的命令不执行且留有分类结果。

#### Scenario: 非 owner 命令被拒
- **WHEN** 命令的提交方不是该 Actor 的当前 owner
- **THEN** 命令被拒绝执行，结果分类含拒绝原因

#### Scenario: 同管线冲突择优
- **WHEN** 同一 Actor 同 Tick 有两条同管线命令
- **THEN** 仅优先级高者执行，另一条被抑制并计数

### Requirement: 结果语义真实
命令结果 MUST 区分内部处置类别（accepted/retryable/replan/invalid/suppressed）与 Screeps 原生返回码；未调用原生 API 时 MUST NOT 伪造原生返回码字段。

#### Scenario: 未调用不伪造
- **WHEN** 命令在校验或仲裁阶段被拒绝，未触达原生 API
- **THEN** 结果只有内部类别与原因，原生返回码字段不存在

#### Scenario: 原生码透传
- **WHEN** 命令执行后原生 API 返回错误码
- **THEN** 结果同时含原生返回码与内部处置类别，两者不混淆

### Requirement: 移动意图统一入口
一切单位移动 MUST 以移动意图进入命令边界，由移动子系统统一执行；直接的原生移动调用只允许出现在移动执行层内部。移动子系统内部的缓存、交通与路径逻辑不受本要求约束。

#### Scenario: 单位不直接寻路
- **WHEN** Agent 决定单位需要移动
- **THEN** 其产出是移动意图（目标/理由/优先级），不包含原生移动调用

#### Scenario: 移动执行层单点
- **WHEN** 移动意图被消费
- **THEN** 原生移动 API 只在移动执行层被调用，交通与缓存行为保持启用前的效率水平

### Requirement: legacy 收编渐进
legacy 模块 MUST 经 Adapter 进入命令边界；在收编完成前，未收编路径 MUST 保持受架构守护清单管辖（总量只减不增）。

#### Scenario: 守护清单只减不增
- **WHEN** 架构守护检查运行
- **THEN** 直连突变调用清单不比上一版本多，新增直连调用必须先登记豁免并给出收编期限

#### Scenario: 人操命令豁免治理
- **WHEN** 玩家通过控制台命令主动执行市场交易、工地操作或孵化
- **THEN** 该调用被守护清单豁免（人操命令层），但必须在豁免清单中登记
