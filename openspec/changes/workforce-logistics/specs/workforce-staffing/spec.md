# Spec Delta

## Purpose

房间劳动力吞吐定编：以 WORK/CARRY 能力口径取代固定只数口径——升级人力目标按采集收入现算并受人口上限约束，搬运定编按运力下界公式现算，采集收入成为全系统单一事实，饥饿信号负反馈收缩升级投入。

## ADDED Requirements

### Requirement: 升级定编 WORK 口径目标
升级人力必须以 WORK 部件总量为目标现算：基线 = 房间采集收入 × 模式档位倍率；水位收缩项（储备低于阈值时按水位等比收缩，不归零）、盈余消耗项（储备高于阈值时消耗盈余）、落地堆清理项（大堆掉落能量折算 WORK）与基线取最大值后输出；输出必须受上限约束（无控制器缓冲时的收紧上限、缓冲在位时的几何上限），并受模式下限保护。全部阈值与系数入配置。

#### Scenario: 收入基线现算
- **WHEN** 房间储备处于正常带且存在升级需求
- **THEN** 升级 WORK 目标以采集收入 × 档位倍率为基线现算，而非固定只数查表

#### Scenario: 低水位收缩不归零
- **WHEN** 房间能量储备水位低于收缩阈值
- **THEN** 升级目标按水位等比收缩，但收缩后不低于模式保底下限（不为零）

#### Scenario: 盈余水位加码
- **WHEN** 房间能量储备水位高于盈余阈值
- **THEN** 升级目标在基线上叠加盈余消耗项

#### Scenario: 大堆落地能量折入目标
- **WHEN** 房间地面掉落能量堆超过可配置规模
- **THEN** 清理该堆所需的 WORK 折入升级目标

### Requirement: count 折算与 RCL 人口上限
WORK 口径目标折算为孵化只数时，必须以当前孵化体型的单只 WORK 数为除数，且折算结果受 RCL 分级人口上限表钳制；被人口上限截断的缺口不得通过超额只数表达，必须由攒能升体型承接。

#### Scenario: 小体型折多只被人口上限截断
- **WHEN** 低能量容量期单只升级体仅 1 个 WORK，WORK 目标折算只数超过该 RCL 人口上限
- **THEN** 在岗目标被钳制在人口上限内，不出现数十只 1-WORK 升级体的编制膨胀

#### Scenario: 上限截断后优先升体型
- **WHEN** 升级编制已到达人口上限且仍有 WORK 缺口
- **THEN** 后续孵化沿攒能定档升体型，而非突破上限继续加只

### Requirement: carrier 运力现算定编
搬运体目标只数必须按运力下界公式现算：Σ(2 × 源单程路程 × 源采集速率 × 冗余系数) ÷ 单件运力，向上取整；单件运力必须读实际孵化体型口径；单程路程缺失实测值的源不参与公式，且任一参与源缺失实测时整体回退保守基线，不得按未知路程编队。

#### Scenario: 实测路程驱动定编
- **WHEN** 各源均已采到实测单程路程且搬运运力不足
- **THEN** 搬运目标只数随 Σ(路程×速率) 增长，距离远的源折出更多搬运编制

#### Scenario: 未实测回退保守基线
- **WHEN** 任一源尚无实测路程（如开局未到岗）
- **THEN** 搬运定编回退保守基线，不按猜测路程放大或缩小编制

### Requirement: 采集收入单一事实口径
房间采集收入必须按在岗采集体现算：Σ 每源 min(源容量再生口径上限, 绑定该源采集体的有效 WORK × 采集功率)，作为定编、诊断与面板的共同输入；升级定编不得以全房历史产出均值替代该现算口径。

#### Scenario: 收入随在岗 WORK 变化
- **WHEN** 采集体死亡或新到岗导致绑定 WORK 变化
- **THEN** 采集收入与依赖它的定编目标同拍变化，无需等待统计窗口

#### Scenario: 源容量封顶
- **WHEN** 某源绑定 WORK 超过源再生口径上限
- **THEN** 该源收入按上限封顶计入，不放大总投入依据

### Requirement: 升级饥饿负反馈
升级单位取能落空且控制器缓冲无货时必须记账（有界上限，按流逝时间惰性衰减）；升级定编必须按记账收缩至模式下限；控制器进入降级风险窗口时豁免记账，不得在保级窗口收缩升级投入。

#### Scenario: 饥饿收缩
- **WHEN** 升级单位持续取能落空使记账累积
- **THEN** 升级定编按记账收缩，能量优先让位采集与搬运

#### Scenario: 记账衰减有界
- **WHEN** 饥饿信号停止（缓冲补货或升级工转岗）
- **THEN** 记账按流逝时间惰性衰减，定编逐步恢复，不需要显式复位

#### Scenario: 保级窗口豁免
- **WHEN** 控制器剩余降级时间进入风险阈值
- **THEN** 取能落空不记账，定编不受饥饿收缩影响
