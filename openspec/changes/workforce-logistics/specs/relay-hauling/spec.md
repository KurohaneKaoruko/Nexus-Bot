# Spec Delta

## Purpose

接力搬运：低等级期以微型搬运件相向对穿整仓交接，货物单 Tick 前进两格、身体不掉头——把长腿运输折叠成短链接力，配合路网配比联动压缩搬运往返成本。

## ADDED Requirements

### Requirement: 相向对穿整仓交接
同房两名搬运体满足全部判据时必须同 Tick 完成整仓能量交接：相位相反（供方满载、受方空载）、意图格互指（对方本 Tick 要踏入的格恰为己方所在格）、单件容量相等、供方剩余寿命高于配置下限。交接后双方以新载量继续原任务方向：任务指派与粘滞状态随货转移（供方转空载取货方向，受方转满载交付方向）；同 Tick 内同一单位不得参与第二次交接（防往复摆振）。

#### Scenario: 交接成立
- **WHEN** 满载搬运体与空载同容量搬运体在通道上相向而行且意图格互指
- **THEN** 供方整仓能量转入受方，双方当 Tick 即按新载量执行（受方继续交付、供方折返取货）

#### Scenario: 状态随货走
- **WHEN** 交接发生时受方已持有指向交付目的地的任务
- **THEN** 交接能量并入该任务口径，供方回到取货侧承接新货源，双方不产生无主能量或双重记账

#### Scenario: 防同 Tick 往复
- **WHEN** 交接刚完成且双方意图格再次互指
- **THEN** 本 Tick 内不再触发第二次交接，需等待下一 Tick

### Requirement: 判据不满足不交接
容量不等、相位同向（双空/双满）、供方寿命低于下限、或目标不在同房时，不得交接，各单位按原任务执行；交接判据的任何一项不满足即整条跳过，不做部分交接。

#### Scenario: 容量不等跳过
- **WHEN** 相向而行的两搬运体单件容量不同
- **THEN** 不发生交接，各自按原任务通行

#### Scenario: 双空载不交接
- **WHEN** 两名空载搬运体意图格互指
- **THEN** 不触发交接逻辑，按普通让路处理

### Requirement: 接力启用等级门
房间等级低于配置等级门时恒启用接力（长途运输按接力链组织）；达到等级门后转大件直运口径（不再强制接力，靠大体型与路网摊薄往返）。

#### Scenario: 低等级期接力
- **WHEN** 房间等级低于等级门且搬运体在通道相遇
- **THEN** 交接判据生效，接力链可形成

#### Scenario: 达门转直运
- **WHEN** 房间等级达到等级门
- **THEN** 新孵化搬运体转大件直运口径，既有接力件自然换代不召回

### Requirement: 接力件体型与路网配比联动
接力期内搬运体必须按微型接力件口径孵化：固定容量基数（CARRY×N）与对应 MOVE 配比入配置，按运力需求以基数倍叠加；房间建成路网覆盖率达到配置阈值时转路面配比（单位 CARRY 占用更少 MOVE）；配比档切换不召回既有单位，经自然换代生效。

#### Scenario: 微型接力件孵化
- **WHEN** 房间处于接力期且需要 200 容量搬运编制
- **THEN** 搬运体按配置的容量基数（如 [C×4, M×2]）口径孵化

#### Scenario: 路网达标转路面配比
- **WHEN** 房间建成路网覆盖率达到阈值
- **THEN** 新孵化搬运体的 MOVE 配比转路面档，沼泽折返成本下降
