# Spec Delta

## Purpose

低频经济模型：周期性估算采集产能、物流吞吐、Spawn 闲置与升级效率，输出瓶颈诊断并据此调整运力目标，配套 docs/nexus-design/06 §6.8 指标观察。

## ADDED Requirements

### Requirement: 低频瓶颈估算
系统必须按低频周期（预算允许时降频运行）估算：Source 可开采产能、采集点持续产量、物流吞吐与等待、Spawn 生产上限与闲置、升级效率；单 Tick 瞬时值不得直接作为估算结论。

#### Scenario: 周期性产出诊断
- **WHEN** 估算周期到达且预算允许
- **THEN** 产出各环节吞吐与闲置的估算结果

#### Scenario: 预算紧张时降频
- **WHEN** CPU 预算紧张
- **THEN** 估算被跳过并计入降级统计，生存与补给行为不受影响

### Requirement: 诊断驱动目标调整
估算结论必须能区分瓶颈类型并调整对应目标：采集多而交付少时优先增加运输能力而非矿工；库存高但 Spawn 缺货时修正物流目的地；生产过剩且无收益目标时将劳动力转向升级。

#### Scenario: 运输瓶颈优先补运力
- **WHEN** 估算显示采集速率明显高于交付速率
- **THEN** 系统提高搬运运力目标，而非继续增加采集单位

#### Scenario: 目的地错配修正
- **WHEN** 房间库存高但 Spawn 仍持续缺货
- **THEN** 诊断指向物流目的地问题并触发配额修正

### Requirement: 经济指标观察
系统必须持续提供以下指标的最新窗口值并可由 HUD/控制台查询：能源净变化、Spawn 因缺能或无计划的闲置 Tick、关键结构缺货 Tick、搬运工运输/等待/空跑占比、采集实际产出对理论产能比例、预留与可用库存比值。

#### Scenario: 指标可查询
- **WHEN** 控制台或 HUD 查询经济指标
- **THEN** 返回各指标最近窗口的数值与更新时间

#### Scenario: 指标反映异常
- **WHEN** 关键结构持续缺货多个窗口
- **THEN** 对应缺货指标持续上升，可被诊断逻辑与人工观察到
