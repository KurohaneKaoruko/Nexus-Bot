# Spec Delta

## Purpose

固定采集工作位：为每个 Source 选定并持有固定工作位，规划 Source 旁容器放置，使矿工驻点稳定生产、占位互斥，采集吞吐可预期。

## ADDED Requirements

### Requirement: 固定工作位选定与持有
每个 Source 必须有确定数量的采集工作位（其相邻可行走格），工作位一经选定在环境不变时保持稳定；采集任务容量等于工作位数量，同一工作位不得被多个单位同时占用。

#### Scenario: 工作位稳定复用
- **WHEN** 采集单位死亡且环境未变
- **THEN** 替补单位继承同一工作位，不重新漂移选点

#### Scenario: 工作位互斥
- **WHEN** 某 Source 的全部工作位已被占用
- **THEN** 采集任务不再接受新分配，多余劳动力流向其他任务

### Requirement: 驻点稳定生产
采集单位必须驻留在其工作位持续采集，不被普通交通挤离固定岗位；仅环境变化（工作位被永久占用/不可通行）时重新选点。

#### Scenario: 岗位不被挤占
- **WHEN** 其他单位路过采集单位的工作位
- **THEN** 采集单位保持驻点继续采集，不被推开

#### Scenario: 环境变化重选
- **WHEN** 原工作位因新建建筑等原因不可通行
- **THEN** 从该 Source 剩余可行走邻格中重新选定工作位

### Requirement: Source 容器放置规划
当房间等级允许建造 Container 时，系统必须为每个 Source 规划其工作位旁的容器放置，并以幂等方式产生建造任务；容器已存在或站点已建时不重复规划，容器被摧毁后可重建。

#### Scenario: 达标后规划容器
- **WHEN** 房间等级满足 Container 需求且该 Source 旁无容器
- **THEN** 产生至多一个该 Source 的容器建造任务

#### Scenario: 幂等不重复
- **WHEN** 容器或其建造站点已存在
- **THEN** 不再为同一 Source 生成重复的容器建造任务
