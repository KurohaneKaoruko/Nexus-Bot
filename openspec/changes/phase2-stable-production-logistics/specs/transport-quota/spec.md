# Spec Delta

## Purpose

运输目标配额：把搬运从「把能量送到某个对象」升级为可计算的资源流——目的地按优先级与最低库存保障竞争运力，货源与批量明确，空载回程可承接新任务。

## ADDED Requirements

### Requirement: 目的地优先级与最低库存保障
搬运目的地必须按优先级与配额竞争运力，关键消费结构（Spawn/Extension）拥有最低库存保障；保障未满足时，低优先级目标不得抢占运力。

#### Scenario: 关键结构优先补货
- **WHEN** Spawn 缺口与升级容器需求同时存在且运力不足
- **THEN** 运力先满足 Spawn 最低库存保障，升级目标等待

#### Scenario: 保障满足后放开
- **WHEN** 关键结构已达最低库存线
- **THEN** 剩余运力按优先级流向其他目的地

### Requirement: 货源与批量明确的搬运任务
搬运任务必须声明货源、目的地、资源类型与批量，并估算往返耗时；不得让搬运工每 Tick 重新选择最近的任意货源。

#### Scenario: 任务绑定货源与目的地
- **WHEN** 产生一条搬运任务
- **THEN** 货源、目的地、批量在任务中明确且存续期内稳定

#### Scenario: 批量匹配运力
- **WHEN** 货源量超过单程可运量
- **THEN** 任务按往返批次估算，不要求单次清空货源

### Requirement: 到达前失效预判
目的地在预计到达前可能已满载或保障已满足时，系统必须重新评估任务价值；已无价值的搬运任务及时终结，不持续占用劳动力。

#### Scenario: 目的地临近满载
- **WHEN** 目的地剩余容量小于在途承运总量
- **THEN** 多余的搬运任务被终结或改派，不再向已满目标运货

### Requirement: 空载回程承接
搬运工完成交付后的空载回程必须可以承接新的运输任务，不强制空跑返回原货源。

#### Scenario: 回程顺路取货
- **WHEN** 搬运工交付后空载且附近存在待运货源
- **THEN** 其回程被分配为新搬运任务，空跑比例计入指标并下降
