# Spec Delta

## Purpose

编队槽位的异构分化：把编队持有的槽位从数量标量升级为带任务种类与能力要求的槽位定义数组，使同一编队内不同槽位可承载不同职能（采集、搬运、护卫混合），并保持编队不直接指挥单位、成员由任务反填的既有不变量。

## ADDED Requirements

### Requirement: 槽位以定义数组表达

编队持有的槽位 MUST 表达为槽位定义数组，每项槽位定义自带其任务种类与所需能力；编队级 MUST NOT 再以单一任务种类或单一能力集合约束全部槽位。槽位总数为数组长度，编队成员仍由槽位任务的 `assignedTo` 反填。编队 MUST NOT 直接持有 Creep 对象或对其发号施令。

#### Scenario: 每槽位独立能力

- **WHEN** 编队声明混合职能（采集位 + 搬运位 + 护卫位）
- **THEN** 每个槽位生成的任务携带各自的任务种类与所需能力，而非全编队共用一套

#### Scenario: 成员由任务反填

- **WHEN** 某个槽位任务被认领
- **THEN** 该 Creep 名字出现在编队成员列表中，且仍执行标准任务

#### Scenario: 槽位总数口径

- **WHEN** 读取编队的期望成员数
- **THEN** 该值等于槽位定义数组长度

### Requirement: 槽位结构变更向后兼容

槽位结构从数量标量变为数组时，既有持久化记录 MUST 被迁移为等价的同质槽位数组：原标量值 N 展开为 N 个与原编队任务种类、能力一致的槽位定义。迁移 MUST NOT 改变编队的存活期限与已有成员，MUST NOT 因坏条目而中断运行。迁移 MUST 幂等。

#### Scenario: 旧记录展开

- **WHEN** 迁移遇到槽位为标量 N 的既有编队记录
- **THEN** 该记录变为 N 个同质槽位定义，任务种类与能力与迁移前一致

#### Scenario: 迁移保留成员与期限

- **WHEN** 迁移一个已有成员且未到期的编队记录
- **THEN** 成员列表与存活期限不变，编队不因迁移而解散或重建

#### Scenario: 坏条目不中断

- **WHEN** 迁移遇到形状非法的编队记录
- **THEN** 该记录回退为安全的空编队形态并告警，迁移继续处理其余记录

#### Scenario: 迁移幂等

- **WHEN** 对同一份数据重复执行迁移
- **THEN** 结果与执行一次相同，不产生重复槽位或累计变形

### Requirement: 异构槽位生命周期一致

槽位的新增、收缩与解散 MUST 保持既有不变量：续期需求的槽位定义少于当前时，多余槽位任务 MUST 被取消而非释放回池；编队解散时全部槽位任务 MUST 被取消；槽位任务 MUST 只清理编队自身命名空间。编队数量与单编队槽位数仍 MUST 受配置上限约束。

#### Scenario: 收缩取消多余槽位

- **WHEN** 续期需求的槽位定义少于当前编队持有的槽位数
- **THEN** 多余槽位任务被取消，编队收缩到需求给出的槽位定义

#### Scenario: 解散取消而非释放

- **WHEN** 编队因到期未续期而解散
- **THEN** 其全部槽位任务被取消，不释放回任务池产生幽灵任务

#### Scenario: 命名空间隔离

- **WHEN** 同一房间同时存在编队槽位任务与规划器直建的防御任务，且编队解散
- **THEN** 只有编队命名空间内的任务被取消，规划器的任务不受影响

#### Scenario: 上限约束

- **WHEN** 异构槽位请求使编队数或单编队槽位数超过配置上限
- **THEN** 超出的部分被裁剪，不突破上限
