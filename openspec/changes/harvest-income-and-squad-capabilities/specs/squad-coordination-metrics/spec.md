# Spec Delta

## Purpose

编队协同行为的表达与收益证据：定义编队级共享目标（领队协调）在不越过意图网关前提下的表达边界，并把协同前后的战损与击杀对比纳入遥测，使「协同带来收益」成为可取证、可开关的判据而非默认前提。

## ADDED Requirements

### Requirement: 领队协调经意图网关表达

编队级共享目标 MUST 只影响单位的目标**选择**，MUST NOT 改变单位执行任务的行为路径，也 MUST NOT 由编队层直接产生游戏动作。所有协同产生的意图 MUST 经统一意图网关提交，与非编队单位走同一仲裁通道。共享目标 MUST 表达在编队持久化记录中，且 MUST 随编队解散一并清除。

#### Scenario: 意图统一仲裁

- **WHEN** 编队因共享目标而改变某成员的行动目标
- **THEN** 该意图经统一意图网关提交并参与既有优先级仲裁，与普通任务意图同规则竞争

#### Scenario: 编队层零游戏动作

- **WHEN** 编队维护共享目标
- **THEN** 编队层不产生任何直接游戏动作，只更新记录与影响目标选择

#### Scenario: 解散即清除

- **WHEN** 编队解散
- **THEN** 其共享目标一并清除，不残留在影响后续编队

#### Scenario: 行为路径不变

- **WHEN** 一个 Creep 处于编队内
- **THEN** 它执行的标准任务路径不因「在编队内」而改变，仅目标选择可被共享目标影响

### Requirement: 编队收益指标入遥测

系统 MUST 记录编队协同前后的收益对比指标（战损、击杀、成员存活时长），基线取编队建立前同房等长窗口的对照值。指标 MUST 可在 sim 与控制台查询中取证，并 MUST 按房有界存储。

#### Scenario: 前后对比可取证

- **WHEN** 查询某房间的编队收益
- **THEN** 可读出该房编队协同前后的战损、击杀与存活时长对比及基线窗口

#### Scenario: 指标按房有界

- **WHEN** 房间长期反复建队与解散
- **THEN** 指标存储保持定长或定数，不随编队次数无界增长

### Requirement: 协同行为默认关闭并以指标为开启门

领队协同与外矿协作等协同行为 MUST 默认关闭，仅当其收益指标达到正向判据时才允许开启；未取得收益证据时 MUST NOT 默认启用。开启判据阈值 MUST 来自配置。

#### Scenario: 默认关闭

- **WHEN** 系统首次部署且未显式开启协同
- **THEN** 编队仅维持槽位协同，不启用领队级共享目标与外矿协作行为

#### Scenario: 指标达标才开启

- **WHEN** 编队收益指标达到配置的正向判据
- **THEN** 协同行为方可被开启；指标为负或缺失时保持关闭

#### Scenario: 指标转负则回收

- **WHEN** 已开启的协同行为其收益指标转为负向
- **THEN** 该行为被关闭，回退到仅槽位协同
