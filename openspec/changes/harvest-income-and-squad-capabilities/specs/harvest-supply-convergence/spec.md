# Spec Delta

## Purpose

采集面供给的双轨合一：把采集体编制与体型定档收敛到单一事实来源，消除新旧两条孵化路径各自定编导致的供给错配，并在 sim 中可取证地修复 P1-14 的采集利用率与升级吞吐塌陷。

## ADDED Requirements

### Requirement: 采集定编单一事实来源

采集编制 MUST 以 workforce 导出的源饱和定编为唯一事实来源；所有孵化路径（任务驱动与 legacy 兜底）MUST 消费同一编制结果。任一路径 MUST NOT 自行按源数或等级表独立推算采集只数。编制按「每源一个驻点采集位」表达，饱和缺口由攒能升体型承接而非拆分多采集位。

#### Scenario: 单一来源供给两路径

- **WHEN** 房间有 N 个源且需要补充采集体
- **THEN** 两条孵化路径请求的采集编制目标均来自同一 workforce 口径，且结果一致

#### Scenario: 无独立口径推算

- **WHEN** 任务驱动路径计算采集编制
- **THEN** 它不得使用「源数取 max(1, N)」这类独立公式，与 workforce 口径保持同一结果

#### Scenario: 饱和缺口由体型承接

- **WHEN** 每源已有一个在岗采集位但源仍有饱和余量
- **THEN** 编制不再拆分额外采集位，缺口通过升体型承接

### Requirement: 采集体型收入感知定档

采集体型预算 MUST 按房间是否存在在岗采集收入分档：有在岗收入时按能量容量定档（攒能升体型）；无在岗收入时按「存量与起步预算取大」定档，且该档位下采集体 WORK 下限为 2。分档判据与全部阈值 MUST 来自配置，MUST NOT 硬编码。

#### Scenario: 有收入按容量定档

- **WHEN** 房间存在在岗采集收入且需要更换采集体
- **THEN** 期望体型按能量容量定档，攒够即产大体型

#### Scenario: 无收入保 2-WORK 底线

- **WHEN** 房间无在岗采集收入（如矿工全灭的涓流期）
- **THEN** 体型按存量与起步预算取大定档，且不产出低于 2 个 WORK 的采集体

#### Scenario: 底线为配置项

- **WHEN** 读取采集体型的 WORK 下限与起步预算
- **THEN** 二者均来自配置表，代码中无字面量阈值

#### Scenario: 既有负收益路径不得复现

- **WHEN** 无收入期需要复产采集体
- **THEN** 不采用「换代立即按存量生产」或「全局硬底线等待」这两种已留档为负收益的路径

### Requirement: legacy 孵化器采集让位契约

legacy 孵化链 MUST NOT 在 workforce 已满足采集编制时再发采集单；仅在 workforce 尚未满足编制（新链路未就绪或异常）时作为兜底发单。让位判定 MUST 由单一配置闸门控制，关闭闸门即恢复 legacy 独立供给，以便回归对照。

#### Scenario: 编制已满足则让位

- **WHEN** workforce 口径下采集编制已满足
- **THEN** legacy 孵化链不发采集单

#### Scenario: 编制未满足则兜底

- **WHEN** workforce 口径下采集编制未满足且无采集缺口在途
- **THEN** legacy 孵化链按兜底契约发单，避免收入断档

#### Scenario: 闸门可回退

- **WHEN** 配置闸门被关闭
- **THEN** legacy 恢复独立供给行为，用于 sim A/B 对照

### Requirement: 源饱和口径实测分解

系统 MUST 按源记录采集工的时间去向分解（在源 / 往返 / 等待），作为采集定编调参与体型决策的证据口径。分解结果 MUST 有界存储，MUST NOT 随 tick 无界增长。

#### Scenario: 时间去向可取证

- **WHEN** 需要判断某源收入未达饱和的原因
- **THEN** 可读出该源采集体在源、往返与等待三类时间上的占比分布

#### Scenario: 存储有界

- **WHEN** 长时间连续运行
- **THEN** 时间分解记录按房按源保持定长或定数，不随 tick 数增长

### Requirement: 采集收敛不得回退既有场景

采集供给收敛 MUST 保持既有场景不回退：冲级场景达 RCL4 验收线，开局、外矿、平地演练场景断言全绿，且全程零未捕获异常。任何一项劣化即视为收敛失败。

#### Scenario: 冲级验收线

- **WHEN** 运行冲级场景至 40000 tick
- **THEN** 控制器等级达到 4，CPU 高分位低于阈值，且无未捕获异常

#### Scenario: 其余场景不回退

- **WHEN** 运行开局、外矿与平地演练场景
- **THEN** 各场景既有断言全部通过，控制器等级时间线不劣于收敛前基线
