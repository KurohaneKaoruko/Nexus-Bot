# Spec Delta

## Purpose

控制器升级缓冲：缩短升级工能量链路——控制器旁缓冲容器（cc）的放置决策、carrier 补货配额流与升级工位就位直供，消除沼泽地形下「采集→搬运→spawn→升级工折返」的链路放大。

## ADDED Requirements

### Requirement: cc 容器放置决策
每个己方房间必须至多持有一个控制器缓冲容器：系统在控制器旁可配置范围内选定缓冲点位并创建容器站点；控制器该范围内已存在容器或容器工地时必须采纳之而非另建；点位被毁后必须可重建；站点创建失败必须按既有失败分类冷却重试，不得每 Tick 重复尝试。布局模块对控制器旁容器点位的让位契约必须保持（布局不得在该范围内另放容器形成建→删→再建循环）。

#### Scenario: 无缓冲容器时选址落位
- **WHEN** 己方房间达到配置的最低 RCL 且控制器配置范围内不存在任何容器或容器工地
- **THEN** 系统选定一个缓冲点位并创建容器工地，同房间该范围内不再重复创建

#### Scenario: 采纳既有容器
- **WHEN** 控制器配置范围内已存在容器（任意来源建造）
- **THEN** 该容器被采纳为缓冲容器，不再新建

#### Scenario: 被毁重建
- **WHEN** 缓冲容器被摧毁且范围内无容器与工地
- **THEN** 系统按原选址决策重新落位

#### Scenario: 布局让位契约不回退
- **WHEN** 布局放量在控制器配置范围内遇到容器点位
- **THEN** 布局跳过该点位，缓冲容器决策是唯一选址权归属

### Requirement: cc 补货配额
缓冲容器必须作为运输配额目的地参与搬运规划：库存低于可配置保障水位（占容量比例，含诊断偏移）时产生补货余量，在途承诺计入已承诺防止超发；其配额优先级必须保证升级供能不断档（不低于供能结构档），房间处于冲级模式时可提升优先级。

#### Scenario: 低于水位进入配额
- **WHEN** 缓冲容器库存加在途承诺低于保障水位
- **THEN** 该容器以余量进入运输目的地配额表，carrier 按配额承接搬运

#### Scenario: 在途承诺防超发
- **WHEN** 缓冲容器已有足额在途搬运承诺
- **THEN** 配额表不再为其产生新的补货余量

#### Scenario: 冲级模式提权
- **WHEN** 房间运行模式为冲级档
- **THEN** 缓冲容器的配额优先级高于和平档，升级供能优先于兜底转运

### Requirement: 升级工位就位直供
缓冲容器存在时，升级单位必须按确定性名册分配到升级工位（缓冲容器相邻且处于控制器升级射程内的可站位），实现 withdraw 与 upgrade 原地完成、零往返；工位分配同 Tick 稳定且互不重复；缓冲容器不存在时必须回退到既有取能链路（锚点取货评分），行为不劣化。

#### Scenario: 就位原地升级
- **WHEN** 升级单位空载且缓冲容器存在
- **THEN** 其取货点为所分配工位相邻的缓冲容器，取满后原地升级，不产生往返移动

#### Scenario: 名册分配稳定
- **WHEN** 同一批升级单位在同一 Tick 内查询工位
- **THEN** 各单位得到的工位互不重复且与名册顺序一致，环境不变时跨 Tick 稳定

#### Scenario: 无缓冲容器回退
- **WHEN** 房间不存在缓冲容器（未建成或被毁）
- **THEN** 升级单位按既有锚点取能链路执行，升级不中断
