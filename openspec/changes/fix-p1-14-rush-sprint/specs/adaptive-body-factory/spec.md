# Spec Delta

## Purpose

自适应体型编译：按能量预算现算角色体型并按房间地形（沼泽密度、路网覆盖率）调整移动部件配比，取代固定段模板，解决沼泽地形往返占比过高的产能塌陷。

## ADDED Requirements

### Requirement: 预算现算体型
经济角色的体型必须按可用预算现算生成：任意预算下生成体型成本不得超过预算；预算低于角色最低孵化下限时必须拒绝生产（不产生死锁体型）；采集角色的 WORK 总数必须受单源再生上限封顶；生成体型部件总数不得超过引擎上限。

#### Scenario: 成本不超预算
- **WHEN** 以任意预算请求某经济角色体型
- **THEN** 生成体型的部件总成本小于等于该预算

#### Scenario: 低于下限拒绝生产
- **WHEN** 预算低于该角色最低孵化下限
- **THEN** 体型编译返回空，孵化请求被跳过

#### Scenario: 采集 WORK 封顶
- **WHEN** 高预算请求采集角色体型
- **THEN** WORK 部件总数不超过单源再生上限折算值

### Requirement: 地形感知移动配比
体型编译必须感知房间地形：按房间沼泽密度与关键通道路网覆盖率把移动配比分档（路网完善时可用低 move 比例的路面组，沼泽密度高且无路网时提高 move 比例），分档阈值与比例必须可配置；地形与路网数据低频刷新且有界缓存，不得每 Tick 全量扫描。

#### Scenario: 沼泽房提高 move 比例
- **WHEN** 房间沼泽密度高于配置阈值且路网覆盖率低于配置阈值
- **THEN** 生成的体型 move 比例高于平地路面组档，重载移动疲劳可被消化

#### Scenario: 平地与路网房不回退
- **WHEN** 房间为平地或关键通道路网覆盖率达标
- **THEN** 体型配比与既有路面组口径一致，不因本能力多耗预算

#### Scenario: 路网建成自动切换
- **WHEN** 房间路网覆盖率随建造达到配置阈值
- **THEN** 后续孵化按路面组档生成体型，无需人工干预

### Requirement: 存量与容量定档语义保持
体型编译升级必须保持既有定档语义：期望体型按能量容量定档、容量未攒够时等待（超时降档兜底）；bootstrap 与应急请求仍按现有存量立即生产且保证开局最低容量可产。战斗角色段模板口径不受本能力影响。

#### Scenario: 攒能定档保持
- **WHEN** 常规请求的房间存量低于容量且等待未超时
- **THEN** 孵化按容量定档的体型等待，不按瞬时存量降档

#### Scenario: 开局最低容量可产
- **WHEN** 房间处于开局最低能量容量（300）
- **THEN** 核心角色仍可产出最小可行体型，不出现无人可产的死锁
