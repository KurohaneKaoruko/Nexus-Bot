# Spec Delta

## Purpose

拉能快递：冲级期把 spawn 盈余能量快速转运到升级端的自爆机制——纯 CARRY 快递爬从 spawn 取满后向控制器/缓冲容器方向自爆，能量就近落入升级消费圈，且绝不挤占基础孵化。

## ADDED Requirements

### Requirement: 发车闸门
快递孵化请求必须同时满足全部闸门才发出：房间非防御应急态；spawn 空闲且孵化队列无积压；控制器升级圈附近存在在工作且按吞吐折算快断能的升级单位；spawn 能量满仓（真盈余）；房间总能量抽走后仍高于运作线（按容量比例可配）。任一闸门不满足必须不发车，闸门阈值全部来自配置。

#### Scenario: 全闸门满足发车
- **WHEN** 五项闸门同时满足
- **THEN** 产生一个纯 CARRY 快递孵化请求

#### Scenario: 防御态不发车
- **WHEN** 房间处于防御应急态
- **THEN** 不产生快递请求，能量留给防御

#### Scenario: 基础孵化优先
- **WHEN** spawn 正在孵化或孵化队列有积压
- **THEN** 不产生快递请求，快递不挤占基础孵化

#### Scenario: 无紧急消费者不发车
- **WHEN** 升级圈内没有快断能的升级单位
- **THEN** 不产生快递请求，避免墓碑能量无消费者

### Requirement: 快递行为与生命周期
快递单位必须为纯 CARRY 体型且预算只取盈余（保留可配置底仓）；交付模式可配置：直投（取满后 transfer 入缓冲容器并复跑多趟，为默认——墓碑中转的衰减漏损实测过大）或自爆（向缓冲容器/控制器方向移动并自爆，能量经墓碑落升级消费圈）；spawn 断供时自爆模式带货就地自爆（半载也交付）、直投模式限时等待后放弃。全部行为经意图网关提交，不得绕过。

#### Scenario: 取满直投交付
- **WHEN** 直投模式快递单位能量取满
- **THEN** 其移动至缓冲容器旁 transfer 卸货，随后返回 spawn 复跑

#### Scenario: 自爆模式交付
- **WHEN** 自爆模式快递单位能量取满（或缓冲容器不存在）
- **THEN** 其向缓冲容器/控制器方向自爆，能量落于升级消费圈

#### Scenario: 空载限时放弃
- **WHEN** spawn 断供且快递单位空载等待超过配置时限
- **THEN** 其自爆退出，不长期占用人口

#### Scenario: 预算保留底仓
- **WHEN** 计算快递体型预算
- **THEN** 预算只取 spawn 存量与运作线之上的盈余，底仓不被抽走

### Requirement: 与房间模式联动
快递机制的总闸必须由房间运行模式档案控制：仅冲级类档位（含可配置的特化子模式判定，如低 RCL 且 spawn 贴控制器、房内无供能链接）激活；常规与低功耗档不激活；判定条件必须可配置。

#### Scenario: 冲级档激活
- **WHEN** 房间为冲级档且特化子模式判定通过
- **THEN** 快递机制可用并按闸门发车

#### Scenario: 常规档不激活
- **WHEN** 房间为常规档或低功耗档
- **THEN** 不产生任何快递请求与快递单位

#### Scenario: 链接接管后退位
- **WHEN** 房内建成供能链接结构
- **THEN** 快递特化子模式停用，正规供能链路接管
