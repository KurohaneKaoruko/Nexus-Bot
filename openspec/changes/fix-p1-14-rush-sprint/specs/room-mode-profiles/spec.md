# Spec Delta

## Purpose

房间运行模式档位：为每个己方房间提供 low/main/high/rush 四档运行参数表与统一解析入口，消费方读参数而非散落字符串比较，支撑冲级特化与后续低功耗降档。

## ADDED Requirements

### Requirement: 模式解析优先级
系统必须为每个己方房间解析出唯一运行模式：显式设置值优先；未设置时按可配置的默认规则取档（含变体级固定档与按 CPU 档位默认冲级/常规，变体固定档用于冲级服等无条件取档的部署形态）；解析结果必须持久化且可观测，模式字段缺失或值非法时必须安全回退常规档，不得抛错。

#### Scenario: 显式设置优先
- **WHEN** 房间的模式字段被显式设置
- **THEN** 解析结果为该显式值，默认规则不覆盖

#### Scenario: 变体固定档优先于自动判档
- **WHEN** 房间未显式设置模式且部署变体声明了固定档（如冲级服 rush）
- **THEN** 所有房间解析为该固定档，CPU 档位判据不参与

#### Scenario: 缺省按 CPU 档取默认
- **WHEN** 房间未显式设置模式且默认规则启用
- **THEN** 按 CPU 档位阈值解析为冲级或常规档

#### Scenario: 非法值安全回退
- **WHEN** 持久化的模式值不在合法集合内
- **THEN** 解析回退常规档且记录告警，运行不中断

### Requirement: 参数表消费契约
每档模式必须提供统一的参数档案，消费方必须通过统一入口读取参数，禁止各自维护模式字符串比较与魔法数；本期参数至少覆盖升级定编倍率与快递总闸，后续消费方扩展参数时必须入参数表而不是新增散落分支；各档参数值必须全部来自配置文件。

#### Scenario: 消费方读档
- **WHEN** 升级定编与快递决策需要模式参数
- **THEN** 两者从统一入口取得的同一房间参数一致

#### Scenario: 定编倍率不超额
- **WHEN** 冲级档的升级定编倍率生效
- **THEN** 定编口径对齐实测收入（倍率为 1），不产生升级任务永久欠账抢占孵化

#### Scenario: 参数改配置即生效
- **WHEN** 配置文件中某档参数值被调整
- **THEN** 重启后消费方读到新值，代码无需改动

### Requirement: 模式变更生效与观测
模式变更必须在下一决策周期生效（不得要求重启或重建房间数据）；HUD 必须展示每房间当前模式，冲级相关面板必须可辨识当前档位。

#### Scenario: 变更后下一周期生效
- **WHEN** 房间模式由常规切换为冲级
- **THEN** 下一决策周期的升级定编与快递闸门按冲级档执行

#### Scenario: HUD 可观测
- **WHEN** 房间面板渲染
- **THEN** 面板包含该房间当前模式标识
