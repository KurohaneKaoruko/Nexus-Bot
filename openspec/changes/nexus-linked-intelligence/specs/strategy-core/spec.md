# Spec Delta

## Purpose

NexusCore 全局战略层：以低频周期与阈值穿越事件重估战略姿态与全局政策，转移带迟滞与原因记录，决策只读预聚合摘要，为下层提供统一战略事实源。

## ADDED Requirements

### Requirement: 战略姿态决策
系统必须维护战略姿态（survive/develop/expand/war）并按低频周期重估；能源库存穿越临界阈值或关键结构持续缺货必须触发立即重估。姿态转移必须满足最小驻留时长（迟滞），并记录转移来源、去向、时间与原因。本期 war 姿态无自动输入源，系统不得在无威胁观测的情况下自动进入 war。

#### Scenario: 低成本库存触发降级
- **WHEN** 能源总库存跌破临界储备线且已过最小驻留时长
- **THEN** 姿态转移为 survive，并记录含库存数值的原因

#### Scenario: 迟滞期内不抖动
- **WHEN** 库存在线附近反复穿越阈值，且当前姿态驻留未达最小时长
- **THEN** 姿态保持不变

#### Scenario: 恢复后回升
- **WHEN** 处于 survive 且库存回升超过健康线并满足驻留时长
- **THEN** 姿态回到 develop

#### Scenario: 过剩时进入扩张准备
- **WHEN** 库存超过过剩线、无瓶颈诊断且无在建工地并满足驻留时长
- **THEN** 姿态转移为 expand

#### Scenario: war 无输入不进入
- **WHEN** 无任何威胁观测输入（本期常态）
- **THEN** 系统不得自动进入 war 姿态

### Requirement: 全局政策输出
战略层必须随姿态输出全局政策：动态能源储备下限、风险容忍度（本期为占位值）、目标库存水平；政策必须持久化并带 schema 版本，迁移可重复执行。

#### Scenario: 政策随姿态调整
- **WHEN** 姿态发生转移
- **THEN** 储备下限与目标库存按新姿态的配置生效并可查询

#### Scenario: 旧 Memory 升级
- **WHEN** 携带旧版本 global 结构的 Memory 被加载
- **THEN** 迁移补全政策字段为安全默认值，且重复迁移结果幂等

### Requirement: 决策输入与成本约束
战略重估必须只读预聚合数据（经济诊断结论、库存累计值、饥饿/闲置累加器、速率摘要），不得遍历游戏对象做实时扫描；重估受 CPU 预算门控，被跳过时旧姿态与旧政策必须继续有效。

#### Scenario: 预算不足时保底
- **WHEN** 战略重估周期到达但 CPU 预算不允许
- **THEN** 重估被跳过并计入降级统计，既有姿态与政策继续生效

#### Scenario: 输入缺失时安全默认
- **WHEN** 战略子系统持久化结构损坏被隔离重置
- **THEN** 姿态回到安全默认（develop）与缺省政策，主循环其余部分不受影响
