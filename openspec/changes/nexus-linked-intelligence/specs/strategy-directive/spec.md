# Spec Delta

## Purpose

指令连结：把全局战略转译为单 Tick 有效的战略指令（姿态、储备下限、任务优先级偏置、升级/建造节流），作为战略下行至局部层的唯一载体，并界定各层的读取边界。

## ADDED Requirements

### Requirement: 指令派生
系统必须在每个 Tick 的局部规划开始前，从持久化战略状态纯派生战略指令；派生必须为 O(1) 常量成本且不依赖当 Tick 战略重估是否运行。指令只在本 Tick 内有效，不得持久化，不得引用游戏 API 对象。

#### Scenario: 战略模块缺席时仍可派生
- **WHEN** 战略模块当 Tick 被预算跳过或被变体开关禁用
- **THEN** 指令仍由既有持久化政策派生，局部规划不受阻塞

#### Scenario: 政策更新下一 Tick 生效
- **WHEN** 战略重估在当 Tick 更新了姿态与政策
- **THEN** 本 Tick 及后续 Tick 的指令反映新政策

### Requirement: 指令消费契约
任务规划层与生产规划层必须消费指令：按姿态对任务种类施加可配置的基础优先级偏置；survive 姿态且库存低于储备下限时必须暂停 upgrade/build 新任务生成，既有任务降权但不取消。个体执行层不得读取指令——战略不逐单位微操，个体保留执行细节自治。

#### Scenario: 告急时压制非关键任务
- **WHEN** 姿态为 survive 且库存低于储备下限
- **THEN** upgrade/build 不再生成新任务，既有 upgrade/build 任务优先级被压低，fill_spawn/harvest 优先级相对抬高

#### Scenario: 恢复后自动解除
- **WHEN** 姿态回到 develop
- **THEN** 优先级偏置与生成暂停全部解除，任务体系按原有基础优先级运行

#### Scenario: 个体不感知战略
- **WHEN** 任一个体执行其已租约任务
- **THEN** 其行动提案由任务与局部观测推导，不直接读取战略指令

### Requirement: 中性退化
战略持久化结构缺失或损坏时，系统必须退化为中性指令（等效 develop 默认政策、零偏置、不节流），且不得抛出异常中断局部规划。

#### Scenario: 结构损坏不扩散
- **WHEN** global 持久化结构缺失或字段非法
- **THEN** 指令派生返回中性指令并按数据错误限频上报，局部规划照常进行
