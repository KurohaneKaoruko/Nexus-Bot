# Spec Delta

## Purpose

建造意图化：规划器只产出建造意图，不直接突变世界；建造放量与在岗建造吞吐联动，杜绝"放量与产能脱钩"的建造风暴。

## ADDED Requirements

### Requirement: 规划只产意图
规划器 MUST 只输出建造/拆除意图（位置、结构类型、优先级），工地创建与移除 MUST 由命令边界的建造管线执行；规划器 MUST NOT 调用工地创建/移除/拆除类原生 API。

#### Scenario: 规划器零突变
- **WHEN** 规划器决定新的布局落位
- **THEN** 世界中出现的工地由建造管线创建，规划器内无原生突变调用

#### Scenario: 拆除同样受管
- **WHEN** 规划器决定移除占位结构或废弃工地
- **THEN** 移除动作以命令提交执行，留有结果记录

### Requirement: 放量与产能联动
新工地的放量 MUST 与在岗建造者的吞吐能力联动：当积压工地数超过在岗产能的可承载倍数（配置阈值）时 MUST 暂缓新工地投放，避免能量与孵化槽被无效工地锁死。

#### Scenario: 积压超限暂缓
- **WHEN** 活跃工地数超过配置的在岗产能承载倍数
- **THEN** 不投放新工地，直至积压回落

#### Scenario: 无积压正常放量
- **WHEN** 建造产能充足且布局有缺口
- **THEN** 工地按规划正常投放，建造进度不停滞

### Requirement: 建造优先级受战略调制
建造管线 MUST 支持按战略阶段调整结构优先级（如冲级期产业类建筑让位、关键经济结构提级）；优先级 MUST 来自配置而非散落在规划器内的硬编码。

#### Scenario: 冲级期产业让位
- **WHEN** 战略处于冲级阶段且能量紧张
- **THEN** 非关键产业结构的建造被暂缓，能量优先保障升级与采集面

#### Scenario: 优先级可配置
- **WHEN** 运维调整结构优先级表
- **THEN** 行为随配置变化，无需代码变更
