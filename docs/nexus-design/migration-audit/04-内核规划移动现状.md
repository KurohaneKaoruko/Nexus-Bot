## 构建变体

| 变体 | 与 main 的差异 | 是否依赖 main 不再用的旧路径 | 说明 |
|---|---|---|---|
| local | 同样 21 个模块、同序；多 `import "../compat"`；`LOCAL_PROFILE` | 否 | `profile.variant` 无人读取 |
| race | 同上，另 `roomMode: "rush"` | 否 | 唯一行为差异在 `strategy/roomMode.ts:45`；D9 同样适用 |
| season | 同 local | 否 | 占位 |
| stronghold | 同 local | 否 | 占位；`energyCheck` 从未关闭（D9），「无限孵化能量」规则未适配 |

`compat.ts`：约 40 个 Screeps 全局类未定义时打空桩；打 `global` 别名；为 `Game.market` 打桩（getHistory、getAllOrders、getOrderById、calcTransactionCost、cancelOrder、changeOrderPrice、extendOrder、createOrder、deal）。main 不导入 compat（Rosmarin 的 compat 只桩 `PowerCreep`）。疑似缺陷（中等置信）：`Game.market` 桩在模块加载时打一次，而引擎每 tick 重建 `Game`，桩大概只在 global reset 那一 tick 有效。
